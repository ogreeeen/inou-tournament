# 異能トーナメント（個人用）

1〜8人で遊ぶ能力者トーナメント。足りない枠はCPUが入って全8人。

- 能力 = 職業（100種）× 属性（炎・水・風・土・雷）× 特殊スキル（30種）
- 1台のスマホを回して、各自「職業4択 → 属性5択 → スキル4択」で選ぶ（引き直しは1回）
- 強さは隠しパラメータ。試合で「鑑定」されてランク S〜E が明らかになる
- 属性は 炎＞風＞土＞雷＞水＞炎。職業・スキルにも相性がある
- 特定の組み合わせで専用イベントが発生（料理人vs鷹匠 → 焼き鳥、など。約75種）
- 試合はRPG風のログで進む。読み上げ・早送り対応

データは `app/src/main/assets/data.js`、ゲーム本体は `index.html`。

BGM：`app/src/main/assets/bgm.mp3`（フリー素材。ごく小さな音量でループ再生、画面上部の🎵でオン・オフ）
