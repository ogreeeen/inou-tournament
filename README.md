# 異能トーナメント（個人用）

自分の能力を文章で入力すると、8人のトーナメントが始まり、試合の様子がRPGのログ風に流れる（読み上げ対応）。

- 能力の文章からキーワードで属性（炎・氷・時間・精神など17種）と強さを読み取り、相性で勝率が変わる
- 一回戦→準決勝→決勝と相手が強くなる
- 決勝のボスは3人からランダム。普通は勝てないが、それぞれ弱点があり、観客のうわさがヒントになる
- 優勝すると倒したボスの数が記録される

ゲーム本体は `app/src/main/assets/index.html`。GitHubにpushするとActionsがAPKを作り、Releases の `latest` に置く。
